## Rencana Teknologi
React + Vite, Tailwind CSS, GSAP (animasi dan parallax), Three.js (3D), dan komponen React Bits. Tampilan glassmorphism berbasis referensi "Blue Bird". Hosting gratis lewat GitHub Pages, Netlify, atau Vercel. Butuh Node.js LTS.

## Cara Menjalankan (setelah website dibuat)
```bash
npm install
npm run dev
```
